Población y muestra

Clave. Antes de calcular nada, preguntate si tenés la población entera o una muestra. Eso decide si dividís por N o por n−1, y si el resultado es un parámetro o una estimación.

Sección 02

Tipos de variable

El tipo de variable determina qué medidas y qué gráficos tenés permitido usar. Es la primera decisión y condiciona todas las demás.

La clasificación

Qué podés hacer con cada una

TipoMedidasGráficos
NominalModa, frecuenciasBarras, torta
OrdinalModa, mediana, cuartilesBarras ordenadas
DiscretaTodasBarras, bastones
ContinuaTodasHistograma, boxplot
Error común. Promediar una variable ordinal. Que la satisfacción esté codificada 1–5 no la vuelve numérica: la distancia entre "malo" y "regular" no es la misma que entre "bueno" y "muy bueno". Usá la mediana.
Clave. Una variable numérica no siempre es cuantitativa. Un DNI, un código postal o el número de camiseta son etiquetas: son nominales aunque estén escritas con dígitos.

Sección 03

Tablas de frecuencia

La forma estándar de resumir una variable: cuántas veces aparece cada valor, en absoluto y en relativo.

Fᵢ/NRelativa acumuladaTermina siempre en 1

Ejemplo — notas de 10 alumnos

NotafᵢFᵢfᵢ/NFᵢ/N

Datos agrupados en intervalos

Cuando hay muchos datos o la variable es continua, se agrupa en clases. El procedimiento es siempre el mismo:

1 · Cantidad de clases       c = redondear(1 + log₂ N)      ← regla de Sturges
2 · Rango                    rango = mayor valor − menor valor
3 · Amplitud                 amplitud = rango / c
4 · Marca de clase           Xᵢ = (límite inferior + límite superior) / 2
Sobre los intervalos. Se escriben [a ; b): el corchete incluye, el paréntesis excluye. Solo el último intervalo cierra con corchete, [a ; b], para que el valor máximo quede adentro. Con variables discretas conviene redondear los límites a valores que la variable pueda tomar realmente.

En Python

df['nota'].value_counts().sort_index()          # fᵢ
df['nota'].value_counts(normalize=True)         # fᵢ/N
df['nota'].value_counts().sort_index().cumsum() # Fᵢ

pd.cut(df['peso'], bins=5)                      # agrupar en 5 intervalos
pd.cut(df['peso'], bins=5).value_counts()       # tabla de datos agrupados
Clave. Sturges es una sugerencia, no una obligación. Si el resultado da clases con formas raras, probá con un número redondo cercano: el objetivo es que la tabla se lea bien.

Sección 05

Tendencia central

Dónde está el centro de los datos. Tres respuestas distintas a la misma pregunta, y no siempre coinciden.

Las tres medidas

Media      x̄ = Σxᵢ / N                    promedio aritmético

Mediana    ordenar los datos, y tomar:
           N impar  → el valor en la posición (N+1)/2
           N par    → el promedio de las posiciones N/2 y N/2+1

Moda       el valor que más se repite

Por qué importa la diferencia

Cuál usar

MedidaUsala cuandoLimitación
MediaLos datos son simétricos y sin outliersMuy sensible a valores extremos
MedianaHay outliers o asimetríaIgnora la magnitud de los valores
ModaLa variable es cualitativaPuede no ser única, o no existir

En Python

df['peso'].mean()      # media
df['peso'].median()    # mediana
df['peso'].mode()      # moda (puede devolver varias)
df['peso'].describe()  # las tres, más dispersión y cuartiles
Clave. Cuando leas "el sueldo promedio", preguntá por la mediana. En variables con cola larga — sueldos, precios, tiempos de espera — la media casi siempre exagera.

Sección 06

Dispersión

Dos grupos pueden tener la misma media y no parecerse en nada. La dispersión mide cuánto se alejan los datos de su centro.

Las cuatro medidas

Rango        rango = mayor valor − menor valor

Varianza     V(X) = Σ(xᵢ − x̄)² / N        queda en unidades²

Desvío       σ = √V(X)                     vuelve a las unidades originales

Coef. de     CV = σ / x̄                    adimensional, se compara entre variables
variación    CV % = (σ / x̄) · 100

Misma media, distinta dispersión

Para qué sirve el coeficiente de variación

PoblaciónMediaσCV
Ratones15 g5 g0,33
Elefantes5.000 kg400 kg0,08

El desvío de los elefantes es 80 veces más grande, pero en relación a su tamaño son más homogéneos que los ratones. Eso es lo que el CV deja ver y el desvío solo, no.

Por qué se eleva al cuadrado. Si se sumaran las desviaciones sin elevarlas, los valores por encima de la media cancelarían a los de abajo y el resultado sería siempre cero. El cuadrado las vuelve todas positivas — y de paso le da más peso a los valores lejanos.

En Python

df['peso'].max() - df['peso'].min()   # rango
df['peso'].var(ddof=0)                # varianza poblacional (÷ N)
df['peso'].var()                      # varianza muestral (÷ n−1) ← por defecto
df['peso'].std(ddof=0)                # desvío estándar
df['peso'].std() / df['peso'].mean()  # coeficiente de variación
Ojo con pandas. var() y std() dividen por n−1 por defecto, no por N. Si estás calculando sobre la población entera y querés que coincida con la fórmula de la clase, pasá ddof=0.

Sección 07

Posición relativa

No dónde está el centro, sino en qué lugar del conjunto cae un valor determinado.

Cuartiles y percentiles

Cuartil    posición de qₖ = k · 0,25 · (N + 1)      k = 1, 2, 3

Percentil  posición de Pₚ = (p / 100) · (N + 1)     p entre 0 y 100

En los dos casos: se ordenan los datos de menor a mayor. Si la posición
da un entero, ese es el valor. Si no, se promedian los dos vecinos.

q₀ es el mínimo, q₂ es la mediana y q₄ el máximo. El percentil 25 es q₁, el 50 es la mediana y el 75 es q₃.

El boxplot los muestra todos

Detectar outliers con el IQR

límite inferior = q₁ − 1,5 · IQR
límite superior = q₃ + 1,5 · IQR

Todo valor fuera de esos límites se marca como atípico.

En Python

df['peso'].quantile([.25, .5, .75])   # los tres cuartiles
df['peso'].quantile(.9)               # percentil 90
df['peso'].rank(pct=True)             # en qué percentil cae cada dato
sns.boxplot(df, x='peso')             # el gráfico
Clave. Hay varios métodos para calcular cuartiles y dan resultados levemente distintos. El de la clase usa 0,25·(N+1); pandas usa interpolación lineal. Con pocos datos la diferencia se nota — no te preocupes si no coincide el último decimal.

Sección 08

Forma de la distribución

Si los datos se reparten parejo a los dos lados del centro, o si se amontonan de un lado.

Los tres casos

Los tres coeficientes

Fisher      γ₁ = Σ(xᵢ − x̄)³ / (N · σ³)

Pearson     Ap = (x̄ − moda) / σ

Bowley–Yule A_BY = (q₃ + q₁ − 2q₂) / (q₃ − q₁)

Los tres se leen igual: positivo → cola a la derecha, cero → simétrica, negativo → cola a la izquierda.

Cuál conviene

CoeficienteUsalo cuando
FisherEs el estándar; lo devuelven todos los programas
PearsonQuerés un cálculo rápido a mano y hay una moda clara
Bowley–YuleHay outliers: se basa en cuartiles, no los sufre
Curtosis. Mide qué tan pesadas son las colas comparadas con una normal. Leptocúrtica (> 0): pico alto y colas gruesas, más valores extremos de lo esperado. Mesocúrtica (= 0): como la normal. Platicúrtica (< 0): aplanada.

En Python

df['peso'].skew()      # asimetría de Fisher
df['peso'].kurt()      # curtosis (0 = normal)
Clave. No hace falta calcular nada para detectar asimetría: si media > mediana, la cola está a la derecha. Es la comprobación de tres segundos.

Sección 09

Probabilidad básica

Un número entre 0 y 1 que mide qué tan posible es un resultado antes de observarlo.

Definición y reglas

P(A) = casos favorables / casos posibles        si todos son equiprobables

0 ≤ P(A) ≤ 1          P(espacio muestral) = 1

Complemento     P(Aᶜ) = 1 − P(A)
Unión           P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
Intersección    P(A ∩ B) = P(A) · P(B|A)
Independientes  P(A ∩ B) = P(A) · P(B)
Condicional     P(A|B) = P(A ∩ B) / P(B)

Unión e intersección

Dos confusiones frecuentes

No es lo mismoDiferencia
Excluyentes /
independientes		Excluyentes: no pueden pasar juntos. Independientes: uno no afecta al otro. Si son excluyentes, no son independientes
P(A|B) / P(B|A)Invertirlas es el error clásico: P(fiebre|gripe) es alta, P(gripe|fiebre) no tanto
Teorema de Bayes. Permite dar vuelta una condicional: P(A|B) = P(B|A) · P(A) / P(B). Sirve cuando conocés la probabilidad en un sentido y necesitás la del otro — por ejemplo, pasar de "qué tan seguido el test da positivo en enfermos" a "qué tan probable es estar enfermo dado un positivo".
Clave. Ante un problema con condicionales, armá una tabla de doble entrada con 1.000 casos. Casi todos los ejercicios se resuelven contando, sin aplicar ninguna fórmula.

Sección 10

Variables aleatorias

Una variable cuyo valor depende del azar. Es el puente entre la probabilidad y la estadística descriptiva.

Discretas y continuas

TipoTomaSe describe con
DiscretaValores contablesP(X = x), función de probabilidad
ContinuaInfinitos valores en un intervalof(x), función de densidad
En las continuas, P(X = x) = 0. No tiene sentido preguntar la probabilidad de que alguien mida exactamente 1,75000… m. Solo se pregunta por intervalos: P(1,70 < X < 1,80), que es el área bajo la curva.

Esperanza y varianza

Esperanza   E(X) = Σ xᵢ · P(xᵢ)          la media teórica, μ

Varianza    V(X) = E(X²) − [E(X)]²      σ² — la fórmula práctica

Desvío      σ = √V(X)

La esperanza es el promedio que se obtendría repitiendo el experimento infinitas veces. No tiene por qué ser un valor posible: la esperanza de un dado es 3,5.

Clave. Las medidas de la unidad 1 y estas son la misma idea vista de dos lados: x̄ es lo que medís en los datos, E(X) es lo que el modelo predice.

Sección 11

Distribuciones discretas

Modelos ya estudiados que describen situaciones típicas. Identificar cuál corresponde es la mitad del ejercicio.

Binomial y Poisson

Cuál usar

DistribuciónCuandoE(X) · V(X)
BernoulliUn solo intento con dos resultadosp · p(1−p)
Binomialn intentos independientes, contás éxitosnp · np(1−p)

GeométricaCuántos intentos hasta el primer éxito1/p

Cómo reconocerlas en el enunciado

Si el problema dice…Es
"de 20 piezas, cuántas defectuosas"Binomial (n = 20)
"llamadas por hora", "clientes por día"Poisson (λ = tasa)
"hasta que salga el primero"Geométrica

En Python

from scipy import stats

stats.binom.pmf(k=3, n=20, p=0.1)   # P(X = 3) exactamente
stats.binom.cdf(k=3, n=20, p=0.1)   # P(X ≤ 3) acumulada
stats.poisson.pmf(k=2, mu=5)        # P(X = 2) con λ = 5
Clave. pmf es la probabilidad de un valor exacto; cdf la de "ese valor o menos". Para "al menos k" usá 1 − cdf(k−1).

Sección 12

Distribución normal

La campana de Gauss. Aparece en todos lados porque cualquier variable que resulte de sumar muchos efectos pequeños tiende a esta forma.

La regla 68 – 95 – 99,7

Estandarizar

z = (x − μ) / σ        cuántos desvíos separan a x de la media

Convierte cualquier normal en la normal estándar (μ = 0, σ = 1), que es la que está tabulada. Un z = 2 significa "dos desvíos por encima del promedio", y eso se interpreta igual sin importar las unidades originales.

En Python

from scipy import stats

stats.norm.cdf(1.96)                   # P(Z ≤ 1,96) = 0,975
stats.norm.cdf(x, loc=mu, scale=sigma) # sin estandarizar a mano
stats.norm.ppf(0.95)                   # el z que deja 95% a la izquierda
Clave. La tabla y cdf siempre dan el área a la izquierda. Para el área a la derecha, restá de 1; entre dos valores, restá las dos acumuladas.

Sección 13

Correlación

Antes de ajustar una recta hay que verificar que haya algo que ajustar. El diagrama de dispersión es el primer paso, siempre.

Covarianza y coeficiente r

Covarianza    S_XY = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n − 1)     signo = dirección

Coeficiente   r = S_XY / (S_X · S_Y)                  entre −1 y 1
de Pearson

La covarianza dice la dirección pero su magnitud depende de las unidades. Dividirla por los desvíos la vuelve adimensional: eso es r.

Qué asociación hay

Cómo leer el valor

|r|Asociación lineal
0,0 – 0,3Débil o nula
0,3 – 0,7Moderada
0,7 – 0,9Fuerte
0,9 – 1,0Muy fuerte

Alternativas

CoeficienteCuándo
PearsonRelación lineal, sin outliers marcados
SpearmanRelación creciente pero curva, o hay outliers
KendallMuestras chicas con muchos empates
Correlación no es causalidad. Que dos variables se muevan juntas no prueba que una cause la otra. Puede haber una tercera variable detrás, o ser pura coincidencia.

En Python

df[['x','y']].cov()                # covarianza
df['x'].corr(df['y'])              # r de Pearson
df['x'].corr(df['y'], method='spearman')
sns.scatterplot(df, x='x', y='y')  # mirar SIEMPRE el gráfico

Sección 14

Regresión lineal simple

Resumir la relación entre dos variables con una recta, para poder estimar Y a partir de X.

El modelo

Modelo teórico     y = β₀ + β₁x + ε

Recta estimada     ŷ = b₀ + b₁x

  β₀, β₁   parámetros poblacionales (desconocidos)
  b₀, b₁   sus estimadores, calculados desde la muestra
  ε        error: la parte de y que x no explica

Mínimos cuadrados

Entre todas las rectas posibles se elige la que hace mínima la suma de los errores al cuadrado, Σ(yᵢ − ŷᵢ)²:

b₁ = S_XY / S²_X = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²

b₀ = ȳ − b₁·x̄       la recta siempre pasa por (x̄, ȳ)

Qué minimiza exactamente

Bondad de ajuste: R²

SCT = Σ(yᵢ − ȳ)²      variabilidad total de y
SCR = Σ(ŷᵢ − ȳ)²      la que explica la recta
SCE = Σ(yᵢ − ŷᵢ)²     la que queda sin explicar

           SCT = SCR + SCE

R² = SCR / SCT = 1 − SCE / SCT

Se lee como porcentaje: un R² = 0,85 significa que la recta explica el 85% de la variabilidad de Y. En regresión simple, R² = r².

Interpretar los coeficientes

TérminoSignifica
b₁ > 0Al subir x, y sube en promedio
b₁ < 0Al subir x, y baja en promedio
b₁Cuánto cambia y por cada unidad de x
b₀Valor de y cuando x = 0 — a veces sin sentido real

Supuestos del modelo

SupuestoCómo se verifica
LinealidadEl diagrama de dispersión muestra una nube alargada
IndependenciaLos residuos no siguen ningún patrón
HomocedasticidadLos residuos tienen dispersión pareja en todo el rango
NormalidadLos residuos se distribuyen normal con media cero
No extrapoles. La recta vale dentro del rango de x que observaste. Estimar fuera de ese rango es suponer que la relación se mantiene donde nunca la mediste.

En Python

import numpy as np
from scipy import stats

r = stats.linregress(df['x'], df['y'])
r.slope        # b₁
r.intercept    # b₀
r.rvalue ** 2  # R²

sns.regplot(df, x='x', y='y')     # dispersión + recta ajustada
Clave. Un R² alto no valida el modelo. Revisá el gráfico de residuos: si dibujan una curva o un embudo, la recta no es la herramienta correcta por más que el número dé bien.

Sección 15

Formulario

Todo lo anterior, junto, para repasar antes de un parcial.

Descriptiva

x̄ = Σxᵢ / N                      media
V(X) = Σ(xᵢ − x̄)² / N            varianza
σ = √V(X)                        desvío estándar
CV = σ / x̄                       coeficiente de variación
rango = máx − mín                rango
IQR = q₃ − q₁                    rango intercuartílico
c = redondear(1 + log₂ N)        clases de Sturges
Xᵢ = (Lᵢ + Lₛ) / 2               marca de clase

Forma

γ₁ = Σ(xᵢ − x̄)³ / (N·σ³)         asimetría de Fisher
Ap = (x̄ − moda) / σ              asimetría de Pearson
A_BY = (q₃ + q₁ − 2q₂)/(q₃ − q₁) asimetría de Bowley–Yule

Probabilidad

P(Aᶜ) = 1 − P(A)                 complemento
P(A ∪ B) = P(A) + P(B) − P(A∩B)  unión
P(A|B) = P(A ∩ B) / P(B)         condicional
P(A|B) = P(B|A)·P(A) / P(B)      Bayes
E(X) = Σ xᵢ·P(xᵢ)                esperanza
V(X) = E(X²) − [E(X)]²           varianza
z = (x − μ) / σ                  estandarización

Regresión

S_XY = Σ(xᵢ − x̄)(yᵢ − ȳ)/(n − 1) covarianza
r = S_XY / (S_X · S_Y)           coeficiente de Pearson
b₁ = S_XY / S²_X                 pendiente
b₀ = ȳ − b₁x̄                     ordenada al origen
ŷ = b₀ + b₁x                     recta estimada
SCT = SCR + SCE                  descomposición
R² = SCR/SCT = 1 − SCE/SCT       bondad de ajuste

El orden de trabajo

01Identificar el tipo de cada variable
02Tabla de frecuencias y gráfico que corresponda
03Tendencia central: media, mediana y moda
04Dispersión: σ y CV
05Cuartiles y boxplot: posición y outliers
06Comparar media con mediana: asimetría
07Si hay dos variables: dispersión y r
08Si hay relación lineal: recta y R²
Clave. Casi todos los ejercicios se resuelven en ese orden. Cuando no sepas por dónde empezar, empezá por el paso 1: el tipo de variable descarta la mitad de las opciones.
