Guías NumPy Cálculo con arrays
Todas las guías

NumPy

La base de todo el cálculo numérico en Python: arrays, operaciones vectorizadas y álgebra lineal. Debajo de pandas, scikit-learn y matplotlib está esto.

Sección 01

Qué es un array

Una lista de Python guarda objetos sueltos repartidos por la memoria. Un array de NumPy guarda números del mismo tipo, uno al lado del otro. Esa sola diferencia lo cambia todo.

Lista contra array

import numpy as np

nums = [1, 2, 3, 4]        # lista de Python
arr  = np.array([1, 2, 3, 4])   # array de NumPy

# Multiplicar por 2
[n * 2 for n in nums]      # hay que recorrer
arr * 2                    # array([2, 4, 6, 8]) — de una

En qué se diferencian

ListaArray
ContenidoCualquier cosa, mezcladaUn solo tipo
TamañoCrece y se achicaFijo al crearlo
MemoriaDispersa, con overheadUn bloque contiguo
OperarCon buclesSobre el array entero
VelocidadBase10 a 100 veces más rápido
Por qué es tan rápido. Los datos están juntos en memoria y todos son del mismo tipo, así que NumPy delega el cálculo a código C compilado que procesa el bloque completo. No hay un bucle de Python interpretando valor por valor. A eso se le llama vectorizar.

Dónde aparece

Casi nunca lo vas a usar solo. Un DataFrame de pandas guarda sus columnas como arrays de NumPy, scikit-learn recibe y devuelve arrays, y matplotlib grafica arrays. Entender NumPy es entender qué pasa abajo de todo lo demás.

Clave. La regla que resume la librería entera: si escribís un for sobre un array, casi seguro hay una forma de evitarlo. Buscala antes de seguir.

Sección 02

Crear arrays

Desde datos que ya tenés, o generados desde cero.

Recetario

# Desde datos
np.array([1, 2, 3])                  # 1 dimensión
np.array([[1, 2], [3, 4]])           # 2 dimensiones
np.array([1, 2, 3], dtype=float)     # forzando el tipo

# Rellenos
np.zeros(5)                          # [0. 0. 0. 0. 0.]
np.ones((2, 3))                      # matriz 2x3 de unos
np.full((2, 2), 7)                   # todo 7
np.eye(3)                            # identidad 3x3

# Secuencias
np.arange(0, 10, 2)                  # [0 2 4 6 8] — el 10 NO entra
np.linspace(0, 1, 5)                 # [0. 0.25 0.5 0.75 1.] — el 1 SÍ entra

# Al azar (API moderna)
rng = np.random.default_rng(42)
rng.random(5)                        # 5 valores entre 0 y 1
rng.integers(1, 7, size=10)          # 10 tiradas de dado
rng.normal(0, 1, 100)                # 100 valores normales

arange o linspace

FunciónSe le indicaEl final
arangeEl paso entre valoresQueda afuera
linspaceCuántos valores querésQueda adentro
No uses arange con decimales. np.arange(0, 1, 0.1) puede darte 10 u 11 elementos según cómo redondee la suma de flotantes. Para pasos decimales, linspace, que te garantiza la cantidad exacta.
Clave. Usá default_rng(semilla) y no np.random.seed(). Es la API recomendada desde NumPy 1.17: cada generador es independiente, así que tu código no se ve afectado por lo que hagan otras librerías con el azar global.

Sección 03

Forma y tipo

Todo array tiene una forma — cuántas dimensiones y de qué tamaño — y un tipo único para todos sus valores. La mayoría de los errores de NumPy son errores de forma.

Anatomía

Recetario

a.shape        # (3, 4)
a.ndim         # 2 dimensiones
a.size         # 12 elementos en total
a.dtype        # int64

# Cambiar la forma
a.reshape(4, 3)      # mismos datos, otra forma
a.reshape(2, -1)     # el -1 se calcula solo: queda (2, 6)
a.ravel()            # aplanar a 1D (vista si se puede)
a.flatten()          # aplanar a 1D (siempre copia)
a.T                  # transponer

# Cambiar el tipo
a.astype(float)
a.astype(np.int32)

Los tipos que vas a ver

dtypeGuardaOjo con
int64EnterosNo admite NaN
float64DecimalesEl default para cálculos
boolTrue / FalseSuma como 1 y 0
objectCualquier cosaPerdés toda la velocidad
Un array entero no acepta decimales. a = np.array([1, 2, 3]); a[0] = 1.9 guarda 1, sin aviso: trunca. Si vas a trabajar con decimales, creá el array como float desde el principio.
Clave. Cuando algo falla, imprimí .shape antes que nada. El 90% de los errores de NumPy son dos arrays cuyas formas no encajan, y el mensaje de error casi siempre te dice exactamente cuáles.

Sección 04

Indexar y cortar

Sacar un elemento, una fila, una submatriz. La sintaxis se parece a las listas, con una diferencia que sorprende: los cortes no copian.

Recetario

# 1 dimensión — igual que una lista
a[0]         # primero
a[-1]        # último
a[1:4]       # del 1 al 3
a[::2]       # salteando de a 2
a[::-1]      # al revés

# 2 dimensiones — [fila, columna]
m[0, 2]      # fila 0, columna 2
m[1]         # fila 1 entera
m[:, 0]      # columna 0 entera
m[0:2, 1:3]  # submatriz
m[:, -1]     # última columna

Vista o copia

OperaciónDevuelve
a[1:3]Vista — comparte memoria
a.reshape(2,2)Vista
a.TVista
a[[0, 2]]Copia — índices sueltos
a[a > 2]Copia — máscara booleana
a.copy()Copia, explícita
Clave. Ante la duda, .copy(). Cuesta memoria pero te ahorra el bug más difícil de rastrear de NumPy: un array que cambia solo porque alguien modificó un corte suyo tres funciones más allá.

Sección 05

Filtrar con máscaras

Seleccionar elementos por una condición en vez de por su posición. Es la forma idiomática de filtrar y la base del filtrado de pandas.

Recetario

a = np.array([1, 5, 3, 8, 2])

# La condición devuelve un array de booleanos
a > 3                     # [False True False True False]

# Usarlo como índice devuelve los que cumplen
a[a > 3]                  # [5 8]

# Combinar: & y | con paréntesis obligatorios
a[(a > 2) & (a < 8)]      # [5 3]
a[(a < 2) | (a > 7)]      # [1 8]
a[~(a > 3)]               # ~ niega: [1 3 2]

# Asignar sobre la selección
a[a < 0] = 0              # pisar los negativos

# Reemplazar según condición, sin modificar
np.where(a > 3, 'alto', 'bajo')
np.where(a > 3, a, 0)     # deja el valor o pone 0
np.clip(a, 0, 5)          # recorta a un rango

# Preguntas rápidas
(a > 3).sum()             # cuántos cumplen — True vale 1
(a > 3).any()             # ¿alguno?
(a > 3).all()             # ¿todos?
np.argmax(a)              # posición del máximo
np.where(a > 3)[0]        # posiciones que cumplen
and y or no funcionan. a[(a > 2) and (a < 8)] lanza ValueError: truth value of an array is ambiguous. Python quiere reducir el array a un solo True o False y no puede. Van & y |, y cada condición entre paréntesis porque tienen menos prioridad que > y <.
Tip. Una máscara es un array como cualquier otro: podés guardarla, reusarla y combinarla. altos = a > 3
pares = a % 2 == 0
a[altos & pares] Además sirve para indexar otro array de la misma forma, que es como se filtran dos columnas relacionadas a la vez.
Clave. a[a > 3] devuelve una copia, así que modificarla no toca el original. Pero a[a > 3] = 0 sí modifica: la asignación sobre una máscara escribe en el array real.

Sección 06

Operaciones vectorizadas

Aplicar un cálculo a todos los elementos escribiéndolo una sola vez. Es lo que hace a NumPy rápido y lo que hace al código corto.

Recetario

a = np.array([1, 2, 3, 4])
b = np.array([10, 20, 30, 40])

# Con un número: se aplica a cada elemento
a + 10        # [11 12 13 14]
a * 2         # [2 4 6 8]
a ** 2        # [1 4 9 16]

# Entre arrays: elemento por elemento, en la misma posición
a + b         # [11 22 33 44]
a * b         # [10 40 90 160]

# Funciones matemáticas (ufuncs)
np.sqrt(a)    np.exp(a)     np.log(a)
np.abs(a)     np.round(a, 2)
np.sin(a)     np.floor(a)   np.ceil(a)

# Comparaciones: devuelven booleanos
a > 2         # [False False True True]
a == b        # elemento por elemento
np.array_equal(a, b)   # ¿son iguales como un todo?

Por qué importa

# Lo mismo, dos formas
resultado = [x**2 + 1 for x in lista]     # bucle de Python
resultado = arr**2 + 1                    # vectorizado

# Con un millón de elementos, el segundo es unas 50 veces más rápido
# y además se lee como la fórmula matemática que representa
* no es multiplicación de matrices. Entre dos arrays 2D, a * b multiplica elemento por elemento. El producto matricial es a @ b. Es un error silencioso: si las formas coinciden, devuelve un resultado válido pero equivocado.
Sobre NaN. np.nan se propaga: cualquier cuenta que lo toque devuelve NaN, y np.nan == np.nan es False. Se detecta con np.isnan(a) y se ignora en los cálculos usando las variantes np.nanmean, np.nansum, np.nanmax.
Clave. Escribí la fórmula como la escribirías en papel. (x - x.mean()) / x.std() estandariza un array entero, sin bucles ni índices, y es literalmente la fórmula de la puntuación z.

Sección 07

Broadcasting

La regla que permite operar arrays de distinta forma sin repetir datos a mano. Es el mecanismo más potente de NumPy y el que más confunde al principio.

Cómo funciona

La regla

Se comparan las formas de derecha a izquierda. Dos dimensiones son compatibles si son iguales, o si alguna vale 1.

(3, 4)  +  (4,)     →  (3, 4)   ✓ la fila se repite en cada fila
(3, 1)  +  (1, 4)   →  (3, 4)   ✓ las dos se estiran
(3, 4)  +  (3,)     →  ERROR    ✗ 4 contra 3, y ninguno es 1
(3, 4)  +  (3, 1)   →  (3, 4)   ✓ la columna se repite

Para qué sirve en la práctica

# Centrar cada columna: restar el promedio de su columna
m - m.mean(axis=0)

# Centrar cada fila: hay que convertir el vector en columna
m - m.mean(axis=1).reshape(-1, 1)
m - m.mean(axis=1, keepdims=True)     # más directo

# Estandarizar todas las columnas de un saque
(m - m.mean(axis=0)) / m.std(axis=0)

# Tabla de multiplicar sin bucles
np.arange(1, 6).reshape(-1, 1) * np.arange(1, 6)
El error que vas a ver. operands could not be broadcast together with shapes (3,4) (3,). Traducido: querés operar por filas pero el vector se está alineando con las columnas. La solución casi siempre es keepdims=True o un .reshape(-1, 1) para convertirlo en columna.
Clave. Escribí las dos formas alineadas a la derecha y comparalas de a pares. Si en cada posición los números son iguales o alguno es 1, la operación va a andar. Si no, ya sabés cuál dimensión arreglar.

Sección 08

Agregar y el parámetro axis

Resumir un array en menos números: la suma, el promedio, el máximo. En 2D hay que decidir si se resume por filas o por columnas, y ahí entra axis.

Qué colapsa cada eje

Recetario

# Sobre todo el array
m.sum()      m.mean()     m.std()
m.min()      m.max()      m.prod()

# Por eje
m.sum(axis=0)    # un total por columna
m.mean(axis=1)   # un promedio por fila

# Posiciones en vez de valores
m.argmin()       m.argmax()
m.argsort()      # las posiciones que lo dejarían ordenado

# Acumulados
a.cumsum()       a.cumprod()

# Ignorando NaN
np.nanmean(a)    np.nansum(a)    np.nanmax(a)

# Otros útiles
np.unique(a)                    # valores distintos, ordenados
np.unique(a, return_counts=True)  # y cuántas veces aparece cada uno
np.sort(a)                      # copia ordenada
np.percentile(a, [25, 50, 75])  # cuartiles
std() divide por N. NumPy usa ddof=0 por defecto, o sea el desvío poblacional. pandas usa ddof=1, el muestral. Los mismos datos dan resultados distintos en una y otra librería. Si necesitás el muestral en NumPy: a.std(ddof=1).
Clave. La regla para no confundirse nunca más: mirá la forma del resultado. Si m tiene forma (3, 4), entonces m.sum(axis=0) devuelve 4 valores y m.sum(axis=1) devuelve 3. Desaparece el eje que nombraste.

Sección 09

Álgebra lineal

Producto de matrices, sistemas de ecuaciones, inversas. Es lo que corre por debajo de una regresión lineal o de una red neuronal.

Recetario

# Producto matricial — usá el operador @
A @ B
np.matmul(A, B)      # lo mismo
np.dot(A, B)         # lo mismo en 2D

# Ojo con la diferencia
A * B                # elemento por elemento, NO es matricial

# Operaciones sobre matrices
A.T                       # transpuesta
np.linalg.inv(A)          # inversa
np.linalg.det(A)          # determinante
np.linalg.matrix_rank(A)  # rango
np.trace(A)               # traza

# Resolver A·x = b
x = np.linalg.solve(A, b)     # preferí esto…
x = np.linalg.inv(A) @ b      # …antes que esto

# Autovalores y autovectores
valores, vectores = np.linalg.eig(A)

# Norma y producto punto
np.linalg.norm(v)
np.dot(u, v)

Las formas tienen que encajar

(m, n) @ (n, p)  →  (m, p)     ✓ el n del medio debe coincidir
(2, 3) @ (3, 4)  →  (2, 4)     ✓
(2, 3) @ (2, 3)  →  ERROR      ✗ 3 contra 2
Un ejemplo con sentido — regresión por mínimos cuadrados. La solución cerrada de una regresión lineal es una línea de NumPy: beta = np.linalg.solve(X.T @ X, X.T @ y) Es exactamente la fórmula que se ve en Probabilidad y Estadística, escrita tal cual.
Clave. Nunca calcules la inversa para resolver un sistema. solve es más rápido y numéricamente más estable: inv acumula error de redondeo, sobre todo con matrices grandes o mal condicionadas.

Sección 10

Números aleatorios

Simular, muestrear y generar datos de prueba. Con una semilla fija, los resultados se pueden reproducir.

Recetario

rng = np.random.default_rng(42)     # la semilla hace reproducible todo lo que sigue

# Distribuciones
rng.random(5)                  # uniforme entre 0 y 1
rng.integers(1, 7, size=10)    # enteros: 1 a 6, el 7 no entra
rng.normal(170, 8, 100)        # normal con media 170 y desvío 8
rng.uniform(10, 20, 5)         # uniforme en un rango
rng.binomial(n=10, p=0.5, size=100)
rng.poisson(lam=3, size=100)

# Muestrear
rng.choice(['a', 'b', 'c'], size=5)               # con reposición
rng.choice(a, size=5, replace=False)          # sin reposición
rng.choice(['a', 'b'], size=10, p=[0.8, 0.2])   # con probabilidades
rng.shuffle(a)                                 # mezcla en el lugar
rng.permutation(a)                             # devuelve mezclado, sin tocar el original

Una simulación completa

# ¿Cuál es la probabilidad de sacar al menos un 6 en 4 tiradas?
rng = np.random.default_rng(42)

tiradas = rng.integers(1, 7, size=(100_000, 4))   # 100.000 experimentos de 4 dados
exito   = (tiradas == 6).any(axis=1)              # ¿alguno fue 6, en cada fila?
exito.mean()                                      # ≈ 0.518

# El valor teórico es 1 − (5/6)⁴ ≈ 0.5177
Por qué default_rng y no np.random.seed. El viejo np.random.seed() configura un estado global compartido por todo el proceso: si una librería que usás también genera azar, tus resultados dejan de ser reproducibles. Un Generator es un objeto tuyo, independiente de lo que haga el resto.
Clave. Poné la semilla siempre que estés desarrollando o mostrando resultados. Sin ella, cada ejecución da números distintos y no podés distinguir un cambio en tu código de la variación normal del azar.

Sección 11

NumPy y pandas

No compiten: pandas está construido sobre NumPy. Saber cuándo bajar de uno al otro te ahorra vueltas.

Cómo se relacionan

NumPypandas
EstructurandarraySeries y DataFrame
EtiquetasNo: solo posicionesSí: índice y nombres de columna
TiposUno para todo el arrayUno por columna
Fuerte enCálculo numérico y matricesDatos tabulares heterogéneos

Ir y volver

# De pandas a NumPy
df.to_numpy()             # todo el DataFrame
df['precio'].to_numpy()   # una columna
df['precio'].values      # lo mismo, forma antigua

# De NumPy a pandas
pd.Series(arr)
pd.DataFrame(matriz, columns=['a', 'b', 'c'])

# Funciones de NumPy aplicadas a columnas de pandas
df['nivel'] = np.where(df['precio'] > 500, 'alto', 'bajo')
df['log']   = np.log1p(df['monto'])
df['cap']   = np.clip(df['monto'], 0, 1000)

Cuándo usar cuál

UsáCuando
pandasLos datos tienen columnas con nombre y tipos distintos
pandasNecesitás agrupar, cruzar tablas o manejar fechas
NumPyEs todo numérico y del mismo tipo
NumPyHay álgebra lineal o matrices de por medio
NumPyVas a pasarle los datos a scikit-learn
Al convertir se pierden las etiquetas. df.to_numpy() devuelve solo los números: se van los nombres de columna y el índice. Y si el DataFrame mezcla texto con números, el array resultante queda como object y perdés toda la velocidad. Convertí solo las columnas numéricas que vas a usar.
Clave. En el trabajo real casi nunca elegís uno u otro: leés con pandas, limpiás con pandas, y bajás a NumPy solo para el cálculo pesado o para entregarle los datos a un modelo.
