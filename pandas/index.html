Sección 01

Series y DataFrame

Las dos estructuras de la librería. Un DataFrame es una tabla; una Series es una sola de sus columnas. Casi todo lo que hagas devuelve una u otra, y saber cuál tenés en la mano evita la mitad de los errores.

Anatomía

Cómo se usa

import pandas as pd

s = pd.Series([1200, 850, 430], index=['a', 'b', 'c'])
s.values      # los datos, como array de numpy
s.index       # las etiquetas
s.dtype       # el tipo (uno solo para toda la Series)

df.shape      # (filas, columnas)
df.columns    # nombres de columnas
df.index      # etiquetas de filas
df.dtypes     # un tipo por columna
df['precio']  # una columna → es una Series

Diferencias que importan

SeriesDataFrame
DimensionesUnaDos
TiposUno soloUno por columna
df.mean()Un númeroUna Series, un valor por columna
Sobre el dtype object. Es el cajón de sastre: aparece cuando la columna tiene texto, o cuando tiene números mezclados con texto. Si una columna que debería ser numérica figura como object, hay algo sucio adentro.
Clave. La alineación por índice es la característica que distingue a pandas de una planilla. s1 + s2 suma los valores que comparten etiqueta y pone NaN donde una de las dos no la tiene — no suma posición contra posición.

Sección 02

Cargar datos

Casi siempre desde un archivo. El 90% de los problemas de carga se resuelven con un parámetro de read_csv.

Cómo se usa

df = pd.read_csv('datos.csv')
df = pd.read_excel('datos.xlsx', sheet_name='Hoja1')
df = pd.read_json('datos.json')

# A mano, para probar cosas
df = pd.DataFrame({
    'producto': ['a', 'b', 'c'],
    'precio':   [1200, 850, 430],
})

Clave. Resolvé los problemas en la carga, no después. Es mucho más simple pasar decimal=',' que arreglar a mano una columna que quedó como texto.

Sección 04

Seleccionar filas y columnas

Sacar un pedazo del DataFrame. Es lo que más se usa y donde más se confunde la gente, porque pandas ofrece varias formas parecidas que no hacen lo mismo.

Las dos formas que importan

df.loc[fila, columna]    # por ETIQUETA — el nombre del índice y de la columna
df.iloc[fila, columna]   # por POSICIÓN — el número de orden, empezando en 0

Etiqueta contra posición

Recetario

# Una columna
df['precio']                    # Series
df[['precio', 'stock']]         # DataFrame (doble corchete)

# Filas
df.loc['b']                     # por etiqueta
df.iloc[1]                      # por posición
df.iloc[0:3]                    # las 3 primeras — el 3 NO entra
df.loc['a':'c']                 # de a hasta c — la 'c' SÍ entra

# Filas y columnas a la vez
df.loc['b', 'precio']           # un valor
df.loc[:, 'precio':'stock']     # todas las filas, un rango de columnas
df.iloc[0:2, [0, 2]]            # 2 filas, columnas 0 y 2

# Filtrar por condición (máscara booleana)
df[df['precio'] > 500]
df[(df['precio'] > 500) & (df['stock'] > 0)]     # & = y
df[(df['precio'] < 100) | (df['activo'])]        # | = o
df[df['categoria'].isin(['A', 'B'])]             # en una lista
df[df['precio'].between(100, 500)]               # en un rango

Qué devuelve cada forma

ExpresiónDevuelve
df['col']Series — una sola columna
df[['col']]DataFrame de una columna
df.loc['b']Series — una fila
df.loc[['b']]DataFrame de una fila
df.loc['b','x']Un valor suelto
Los tres errores clásicos.

1. Usar and / or al filtrar. Van & y |, y cada condición entre paréntesis: df[(a > 1) & (b < 2)]. Con and tirás ValueError: truth value of a Series is ambiguous.

2. Esperar que el corte de .loc excluya el final. .iloc[0:3] trae 3 filas; .loc['a':'c'] trae 3 también, pero porque incluye la 'c'. Es la única parte de Python donde el final entra.

3. Encadenar corchetes para asignar. df[df.precio > 5]['stock'] = 0 no modifica nada y avisa con SettingWithCopyWarning. Va en un solo .loc: df.loc[df.precio > 5, 'stock'] = 0.

Alternativas

En vez deCuándo conviene
df.query()Filtros largos: df.query('precio > 500 and stock > 0') se lee mejor
df.filter()Elegir columnas por patrón en el nombre: filter(like='fecha')
df.at / df.iatUn solo valor: es más rápido que .loc / .iloc
df.nlargest(5,'x')El top 5 — evita ordenar todo y después cortar
df.sample(10)Una muestra al azar en vez de las primeras filas
Tip. Una máscara booleana es un objeto en sí misma. Si la guardás en una variable, el filtro se lee como una frase y podés reutilizarla: caros = df['precio'] > 500
sin_stock = df['stock'] == 0
df[caros & sin_stock]
Clave. Ante la duda, .loc. Es explícito, funciona con etiquetas y con máscaras booleanas, y es la única forma segura de asignar. Dejá .iloc para cuando realmente te importe la posición — recorrer, partir en bloques, tomar la última fila con .iloc[-1].

Sección 05

Ordenar

Por los valores de una o varias columnas, o por el índice.

Recetario

df.sort_values('precio')                       # ascendente
df.sort_values('precio', ascending=False)      # descendente
df.sort_values(['cat', 'precio'],              # varias claves
               ascending=[True, False])
df.sort_values('precio', na_position='first')  # dónde van los NaN
df.sort_index()                                # por las etiquetas de fila

df.nlargest(5, 'precio')                       # top 5, más directo
df.nsmallest(5, 'precio')
df['precio'].rank(ascending=False)             # puesto de cada fila
Ordenar no modifica el DataFrame. df.sort_values('x') devuelve una copia ordenada. Si no la asignás, no pasa nada: df = df.sort_values('x'). Vale para casi todos los métodos de pandas.
Tip. Después de ordenar, el índice queda desordenado. Si te molesta, .reset_index(drop=True) lo renumera; sin drop=True el índice viejo se convierte en una columna.
Clave. Para un top N usá nlargest, no sort_values().head(). Dice mejor la intención y no ordena el resto de las filas al pedo.

Sección 06

Crear y modificar columnas

Calcular una columna nueva a partir de las que ya tenés. Casi siempre es una operación entre columnas enteras, sin recorrer nada.

Recetario

# Operaciones entre columnas: se aplican fila por fila solas
df['total'] = df['precio'] * df['cantidad']
df['iva']   = df['total'] * 0.21

# Condicional
import numpy as np
df['caro'] = np.where(df['precio'] > 500, 'sí', 'no')

# Varias condiciones
df['nivel'] = np.select(
    [df['precio'] > 1000, df['precio'] > 500],
    ['alto', 'medio'],
    default='bajo')

# Cortar en intervalos
df['rango'] = pd.cut(df['edad'], bins=[0, 18, 65, 120],
                     labels=['menor', 'adulto', 'mayor'])

# Traducir valores uno a uno
df['pais'] = df['cod'].map({'AR': 'Argentina', 'BR': 'Brasil'})

# Renombrar, borrar, cambiar tipo
df = df.rename(columns={'precio_unit': 'precio'})
df = df.drop(columns=['temporal'])
df['cantidad'] = df['cantidad'].astype('int')

Cuándo usar cada herramienta

HerramientaParaVelocidad
columna * 2Aritmética directaLa más rápida
np.whereUna condición, dos resultadosRápida
np.selectVarias condicionesRápida
.map()Traducir valor por valor con un dictRápida
.apply()Lógica que no entra en lo anteriorLenta: es un bucle
No recorras el DataFrame con un for. for i, fila in df.iterrows() es cientos de veces más lento que operar sobre la columna entera. Si te encontrás escribiendo un bucle, casi seguro hay una operación vectorizada que hace lo mismo en una línea.
Tip — encadenar con assign. Permite crear varias columnas seguidas sin repetir el nombre del DataFrame: df = df.assign(
    total = df.precio * df.cantidad,
    iva = lambda d: d.total * 0.21) Fijate que iva usa lambda porque necesita la columna total recién creada.
Clave. Pensá en columnas enteras, no en filas. Es el cambio mental que separa usar pandas de escribir Python adentro de pandas.

Sección 07

Valores faltantes

Detectarlos, entender por qué faltan y decidir qué hacer. La decisión es del análisis, no de pandas.

Recetario

# Detectar
df.isna().sum()                    # cuántos por columna
df.isna().sum() / len(df) * 100    # en porcentaje
df[df['precio'].isna()]            # ver las filas afectadas

# Eliminar
df.dropna()                        # filas con algún NaN
df.dropna(subset=['precio'])       # solo si falta esa columna
df.dropna(axis=1)                  # columnas con algún NaN
df.dropna(thresh=3)                # dejar las que tengan 3+ valores

# Rellenar
df['precio'].fillna(df['precio'].median())
df['cat'].fillna('Sin dato')
df['serie'].ffill()                # arrastrar el anterior
df['serie'].interpolate()          # interpolar entre vecinos

Qué estrategia

EstrategiaCuándo
Eliminar filasFaltan pocas y no siguen ningún patrón
Eliminar columnaFalta más del 50%
MedianaNumérica con outliers
ModaCategórica
"Sin dato"El hueco significa algo: no aplica, no respondió
ffillSerie temporal ordenada
NaN no es igual a nada, ni a sí mismo. df[df['x'] == None] no devuelve nada nunca. Se pregunta con .isna() y .notna().
Clave. Antes de rellenar, mirá dónde faltan. Si todos los faltantes están en las mismas filas, hubo una falla de carga y conviene sacar esas filas, no imputar cada columna por separado.

Sección 08

Texto

Todos los métodos de string de Python, aplicados a una columna entera con el accesor .str.

Recetario

# Limpiar — el combo estándar
df['ciudad'] = df['ciudad'].str.strip().str.lower()

# Consultar
df['mail'].str.contains('@gmail')      # máscara booleana
df['cod'].str.startswith('AR')
df['nombre'].str.len()

# Modificar
df['tel'].str.replace('-', '', regex=False)
df['nombre'].str.title()               # Cada Palabra Así
df['texto'].str.slice(0, 10)           # o df['texto'].str[:10]

# Partir en columnas
df[['nombre', 'apellido']] = df['completo'].str.split(' ', n=1, expand=True)

# Extraer con expresión regular
df['anio'] = df['ref'].str.extract(r'(\d{4})')

Problemas típicos

SíntomaSolución
"Buenos Aires" ≠ "buenos aires ".str.strip().str.lower()
Números como textopd.to_numeric(col, errors='coerce')
"1.234,56" no convierteSacar el punto y cambiar la coma por punto primero
Falla con NaNRellenar antes, o usar na=False en contains
Tip. Antes de agrupar por una columna de texto, corré siempre df['col'].value_counts(). Vas a descubrir que "SI", "Si" y "sí " son tres categorías distintas para pandas.
Clave. Sin el .str no funciona nada: df['col'].lower() falla, df['col'].str.lower() anda. El accesor es lo que aplica el método a cada valor.

Sección 09

Fechas

Una vez convertidas a datetime, se pueden ordenar, restar, agrupar por mes y filtrar por rango. Como texto, nada de eso funciona.

Recetario

# Convertir — siempre lo primero
df['fecha'] = pd.to_datetime(df['fecha'])
df['fecha'] = pd.to_datetime(df['fecha'], format='%d/%m/%Y')
df['fecha'] = pd.to_datetime(df['fecha'], errors='coerce')   # inválidas → NaT

# Extraer partes con el accesor .dt
df['anio']    = df['fecha'].dt.year
df['mes']     = df['fecha'].dt.month
df['dia_sem'] = df['fecha'].dt.day_name()
df['periodo'] = df['fecha'].dt.to_period('M')    # 2026-09

# Filtrar por rango
df[df['fecha'] >= '2026-01-01']
df[df['fecha'].between('2026-01-01', '2026-03-31')]

# Diferencias
df['dias'] = (df['fin'] - df['inicio']).dt.days

# Agrupar por período (requiere el índice en fechas)
df.set_index('fecha').resample('M')['ventas'].sum()

Códigos de formato y frecuencia

CódigoFormatoFreqPeríodo
%dDía 01–31DDía
%mMes 01–12WSemana
%YAño 2026MFin de mes
%yAño 26QTrimestre
%H:%MHora y minutoYAño
Cuidado con el orden día/mes. 03/04/2026 es ambiguo y pandas puede leerlo como 3 de abril o 4 de marzo. Si las fechas vienen en formato argentino, pasá dayfirst=True o el format explícito. Un error acá no lanza ninguna excepción: simplemente quedan mal.
Clave. Convertí las fechas apenas cargás el archivo — con parse_dates= en read_csv, mejor todavía. Todo lo demás depende de eso.

Sección 10

Agrupar

Calcular un resumen por categoría: el promedio por sucursal, el total por mes. Es la operación más potente de la librería.

Partir, aplicar, combinar

Recetario

df.groupby('cat')['valor'].sum()
df.groupby('cat')['valor'].mean()
df.groupby('cat').size()                   # cuántas filas por grupo
df.groupby(['cat', 'anio'])['valor'].sum() # dos niveles

# Varias métricas a la vez, con nombres propios
df.groupby('cat').agg(
    total   = ('valor', 'sum'),
    promedio= ('valor', 'mean'),
    casos   = ('valor', 'count'))

# Que la clave quede como columna y no como índice
df.groupby('cat', as_index=False)['valor'].sum()

# Devolver un valor por FILA, no por grupo
df['prom_cat'] = df.groupby('cat')['valor'].transform('mean')
df['dif'] = df['valor'] - df['prom_cat']

agg, transform o filter

MétodoDevuelvePara
.agg()Una fila por grupoUn resumen
.transform()Una fila por fila originalComparar cada fila con su grupo
.filter()Las filas de los grupos que cumplenQuedarse con grupos grandes
groupby descarta los NaN de la clave. Las filas cuya categoría es nula desaparecen del resultado sin aviso. Si te importan, usá dropna=False.
Clave. transform es el que más cuesta y el que más resuelve: devuelve el valor del grupo repetido en cada fila, así podés comparar cada registro contra el promedio de su categoría sin hacer un merge.

Sección 11

Tablas dinámicas

Reacomodar la tabla: pasar categorías a columnas para comparar, o al revés.

Largo y ancho

Recetario

# Largo → ancho
df.pivot_table(index='mes', columns='sucursal',
               values='ventas', aggfunc='sum')

df.pivot_table(index='mes', columns='sucursal', values='ventas',
               aggfunc='sum', margins=True, fill_value=0)  # con totales

# Ancho → largo
df.melt(id_vars='mes', var_name='sucursal', value_name='ventas')

# Conteo cruzado de dos categóricas
pd.crosstab(df['cat'], df['region'])
pd.crosstab(df['cat'], df['region'], normalize='index')   # en %

Cuál usar

FunciónPara
pivot_tableResumen cruzado con una función de agregación
pivotIgual pero sin agregar: falla si hay duplicados
crosstabContar combinaciones de dos categóricas
meltVolver al formato largo
Clave. Si pivot te tira ValueError: Index contains duplicate entries, es que hay más de un valor por celda. Usá pivot_table, que te obliga a decidir cómo combinarlos.

Sección 12

Combinar tablas

Pegar dos DataFrames: uno debajo del otro, o uno al lado del otro cruzando por una clave.

Los cuatro tipos de merge

Recetario

# Al lado, cruzando por una clave
pd.merge(ventas, clientes, on='id_cliente', how='left')

pd.merge(a, b, left_on='cod', right_on='codigo', how='left')   # claves con distinto nombre
pd.merge(a, b, on='id', how='left', indicator=True)            # marca de dónde vino cada fila
pd.merge(a, b, on='id', suffixes=('_2025', '_2026'))           # columnas repetidas

# Uno debajo del otro
pd.concat([enero, febrero], ignore_index=True)

# Uno al lado del otro, por posición/índice
pd.concat([a, b], axis=1)
Controlá las filas antes y después. Si len(df) creció después de un merge, la clave está duplicada en la tabla derecha y se multiplicaron las filas. Verificalo con b['id'].duplicated().any() antes de cruzar.
Tip. indicator=True agrega una columna _merge que dice si cada fila vino de la izquierda, de la derecha o de las dos. Es la forma más rápida de descubrir por qué faltan datos después de un cruce.
Clave. merge cruza por valores de una columna; concat apila. Si estás pegando meses de un mismo reporte, es concat. Si estás agregando datos del cliente a cada venta, es merge.

Sección 13

Exportar

Guardar el resultado para compartirlo o seguir trabajando después.

Recetario

df.to_csv('salida.csv', index=False)
df.to_csv('salida.csv', index=False, sep=';', decimal=',')   # para Excel en español
df.to_excel('salida.xlsx', index=False, sheet_name='Datos')
df.to_parquet('salida.parquet')      # conserva los tipos, pesa mucho menos

# Varias hojas en un mismo Excel
with pd.ExcelWriter('reporte.xlsx') as w:
    ventas.to_excel(w, sheet_name='Ventas', index=False)
    resumen.to_excel(w, sheet_name='Resumen')

Qué formato

FormatoCuándo
CSVCompartir con cualquiera; lo abre todo
ExcelLo va a leer una persona, con varias hojas
ParquetUso propio: rápido, liviano y conserva los dtypes
Acordate de index=False. Sin eso, el índice se guarda como una primera columna sin nombre. Al volver a cargar el archivo aparece como Unnamed: 0, y si repetís el ciclo se van acumulando.
Clave. El CSV guarda todo como texto: los tipos se pierden y hay que volver a declararlos al cargar. Si el archivo es un paso intermedio de tu propio trabajo, usá Parquet.

Sección 14

Recetario final

El flujo completo, en el orden en que se suele escribir.

Un análisis de principio a fin

import pandas as pd
import numpy as np

# 1 · Cargar
df = pd.read_csv('ventas.csv', sep=';', decimal=',', parse_dates=['fecha'])

# 2 · Revisar
df.info()
df.isna().sum()
df.duplicated().sum()

# 3 · Limpiar
df = df.drop_duplicates()
df['sucursal'] = df['sucursal'].str.strip().str.title()
df['precio'] = df['precio'].fillna(df['precio'].median())

# 4 · Enriquecer
df['total'] = df['precio'] * df['cantidad']
df['mes']   = df['fecha'].dt.to_period('M')

# 5 · Filtrar
df = df[df['total'] > 0]

# 6 · Resumir
resumen = (df.groupby(['mes', 'sucursal'], as_index=False)
             .agg(total=('total', 'sum'), operaciones=('total', 'count'))
             .sort_values('total', ascending=False))

# 7 · Guardar
resumen.to_csv('resumen.csv', index=False)
