Análisis Exploratorio de Datos

Qué mirar en un dataset, con qué código, y qué usar cuando lo habitual no alcanza.

Sección 01

Qué es el EDA

Conocer los datos antes de modelarlos. No busca una respuesta: busca las preguntas correctas y los problemas que arruinarían todo lo que venga después.

El recorrido

PasoPregunta que responde
Estructura¿Cuántas filas y columnas? ¿De qué tipo?
Calidad¿Faltan datos? ¿Hay duplicados o errores?
Distribución¿Cómo se reparte cada variable por separado?
Relación¿Cómo se mueven las variables entre sí?
Clave. El EDA no es lineal. Cada hallazgo te hace volver un paso atrás: es normal y es la señal de que está funcionando.

Sección 02

Cargar y mirar

Los primeros treinta segundos con un dataset nuevo: tamaño, aspecto de las filas y si se cargó bien.

Cómo se usa

import pandas as pd

df = pd.read_csv('datos.csv')

df.shape        # (filas, columnas)
df.head()       # primeras 5
df.tail()       # últimas 5 → ¿se cortó la carga?
df.sample(5)    # 5 al azar → más honesto que head()
df.columns      # nombres reales de las columnas

Qué mirar

SíntomaQué suele significar
1 sola columnaseparador equivocado → sep=';'
Cabecera como filaheader=None o filas de título → skiprows=
Acentos rotoscodificación → encoding='latin-1'
Números como textocoma decimal → decimal=','
Últimas filas vacíaspie de página en el archivo original

Alternativas

En vez de read_csvCuándo
pd.read_excel()el archivo es .xlsx (requiere openpyxl)
pd.read_json()viene de una API
read_csv(nrows=1000)el archivo es enorme y solo querés espiarlo
sns.load_dataset()estás practicando y no tenés datos propios
Clave. Usá sample() además de head(): las primeras filas suelen estar ordenadas y no representan al resto.

Sección 03

Tipos de datos

Pandas adivina el tipo de cada columna al cargar, y a veces se equivoca. Un tipo mal asignado hace que las estadísticas y los gráficos den cualquier cosa.

Cómo se usa

df.dtypes       # tipo de cada columna
df.info()       # tipos + nulos + memoria, todo junto

# Corregir
df['fecha']  = pd.to_datetime(df['fecha'])
df['precio'] = pd.to_numeric(df['precio'], errors='coerce')
df['ciudad'] = df['ciudad'].astype('category')

Qué mirar

dtypeEs correcto paraSospechá si…
int64conteos, IDses un ID y lo vas a promediar
float64medidas continuasdebería ser entero → hay nulos
objecttexto libreson números o fechas mal leídos
categorypocas etiquetas repetidas—
datetime64fechas y horasquedó como object → no podés ordenar
Clave. errors='coerce' convierte lo que no puede parsear en NaN en lugar de fallar. Después contá esos nulos: te dicen cuántos valores estaban sucios.

Sección 04

Valores faltantes

Cuántos faltan importa menos que por qué faltan. El patrón de los huecos suele ser información en sí mismo.

Cómo se usa

df.isnull().sum()                       # cuántos por columna
df.isnull().sum() / len(df) * 100       # en porcentaje
df.isnull().sum(axis=1).value_counts()  # cuántos por fila

El patrón importa

Alternativas

EstrategiaCuándo
df.dropna()faltan pocas filas y son al azar
df.drop(columns=…)la columna tiene más del 50% vacío
fillna(df[c].median())numérica con outliers
fillna(df[c].mode()[0])categórica
fillna('Sin dato')el hueco significa algo (no aplica, no respondió)
fillna(method='ffill')serie temporal ordenada
Clave. Rellenar con la media achica artificialmente la dispersión. Si vas a imputar mucho, agregá una columna booleana que marque dónde había un hueco.

Sección 05

Estadísticas descriptivas

Un resumen numérico de cada columna: dónde está el centro, cuánto se dispersa y hasta dónde llega.

Cómo se usa

df.describe()                      # solo numéricas
df.describe().T                    # una fila por variable → más legible
df.describe(include='all').T       # numéricas + categóricas

Qué mirar

MétricaAlerta si…
countes menor que el total de filas → hay faltantes
stdvale 0 → columna constante, se puede descartar
mines negativo donde no corresponde → error de carga
maxestá muy lejos del 75% → outliers
mean vs 50%difieren mucho → distribución sesgada

El caso típico

Alternativas

En vez de describe()Cuándo
df.info()querés tipos y nulos, no estadísticas
df.value_counts()la columna es categórica
df.quantile([.01,.99])necesitás cortes distintos a los cuartiles
df.groupby(c).describe()el resumen debe ser por grupo
sns.boxplot()preferís ver los cuartiles que leerlos
Clave. Compará mean contra 50%. Si difieren, resumí con la mediana, no con el promedio.

Sección 06

Variables categóricas

Para las columnas de texto o etiquetas, la pregunta no es el promedio: es cuántas categorías hay y cómo se reparten.

Cómo se usa

df['col'].nunique()                    # cuántas categorías distintas
df['col'].value_counts()               # frecuencia de cada una
df['col'].value_counts(normalize=True) # en proporción

pd.crosstab(df['a'], df['b'])          # cruce de dos categóricas
sns.countplot(x='col', data=df)        # lo mismo, en barras

Qué mirar

HallazgoQué hacer
1 categoríala columna no aporta nada: descartala
Casi tantas como filases un ID, no una categoría
Clase con 98%dataset desbalanceado: cuidado al modelar
"SI", "Si", "sí"normalizá: .str.strip().str.lower()
Cola de rarasagrupalas en "Otros"
Clave. value_counts() ignora los nulos por defecto. Usá dropna=False para que aparezcan junto al resto.

Sección 07

Distribuciones

La forma de una variable numérica: dónde se concentra, si es simétrica y si hay más de un pico.

Cómo se usa

import seaborn as sns

sns.histplot(df, x='col', bins=30)          # frecuencias
sns.histplot(df, x='col', kde=True)         # + curva suavizada
sns.boxplot(df, x='col')                    # cuartiles y outliers
sns.histplot(df, x='col', hue='grupo')      # comparar grupos

Las formas y qué significan

Alternativas

GráficoCuándo conviene
histplotuna variable, querés ver la forma real
kdeplotcomparar 2–3 grupos superpuestos
boxplotcomparar muchos grupos de un vistazo
violinplotel boxplot esconde la forma (bimodales)
ecdfplotno querés depender de la cantidad de bins
Clave. Probá dos o tres valores de bins. Con muy pocos se pierden los picos; con demasiados, todo parece ruido.

Sección 08

Outliers

Valores muy alejados del resto. Pueden ser errores de carga o los casos más interesantes del dataset: hay que mirarlos antes de decidir.

Cómo se usa

# Regla del rango intercuartílico (IQR)
q1, q3 = df['col'].quantile([.25, .75])
iqr  = q3 - q1
bajo, alto = q1 - 1.5*iqr, q3 + 1.5*iqr

fuera = df[(df['col'] < bajo) | (df['col'] > alto)]
print(len(fuera))
fuera.head()    # mirarlos SIEMPRE antes de tocar nada

Cómo se lee un boxplot

Alternativas

Qué hacerCuándo
Dejarloes un valor real y válido (lo más común)
Corregirloes un error tipeado evidente (edad = 999)
Eliminarloes imposible y son muy pocos casos
Recortar (clip)querés limitar el efecto sin perder la fila
Transformarla cola es larga → np.log1p()
Clave. En distribuciones sesgadas, el IQR marca outliers que son perfectamente normales. Es una regla, no un veredicto.

Sección 09

Relaciones entre variables

Ya conocés cada columna por separado. Ahora: cómo se mueven juntas.

Cómo se usa

# numérica vs numérica
sns.scatterplot(df, x='a', y='b', hue='grupo')

# numérica vs categórica
df.groupby('grupo')['valor'].mean()
sns.boxplot(df, x='grupo', y='valor')

# todo contra todo (pocas columnas)
sns.pairplot(df, hue='grupo')

Qué buscar en un scatter

Alternativas

GráficoCuándo conviene
scatterplotdos numéricas, pocos puntos
hexbin / kdeplotmiles de puntos: el scatter se satura
lineplotel eje X es tiempo
barplotcomparar un promedio entre categorías
pairplotexploración inicial, menos de 6 columnas
Clave. pairplot con muchas columnas tarda muchísimo y no se lee. Filtrá primero las que te interesan.

Sección 10

Correlación

Un número entre −1 y 1 que resume qué tan juntas se mueven dos variables numéricas.

Cómo se usa

num  = df.select_dtypes(include='number')
corr = num.corr()

sns.heatmap(corr, annot=True, cmap='coolwarm', vmin=-1, vmax=1)

# solo contra la variable objetivo, ordenado
corr['objetivo'].sort_values(ascending=False)

Cómo leer el valor

|r|Interpretación
0,0 – 0,3débil: prácticamente no hay relación lineal
0,3 – 0,7moderada: hay tendencia, con dispersión
0,7 – 0,9fuerte: se predicen bastante bien entre sí
> 0,9redundante: sacá una de las dos

Lo que la correlación no ve

Alternativas

MétodoCuándo
corr()Pearson: relación lineal, sin outliers fuertes
corr('spearman')relación monótona pero curva, o hay outliers
pd.crosstab()las dos variables son categóricas
groupby().mean()una categórica y una numérica
Clave. Correlación no es causalidad, y r = 0 no significa "sin relación": significa "sin relación lineal".

Sección 11

Checklist

El recorrido mínimo para cualquier dataset nuevo, en orden.

01shape, head, sample — tamaño y aspecto
02info, dtypes — tipos correctos
03duplicated().sum() — filas repetidas
04isnull().sum() — cuántos faltan y dónde
05describe().T — rangos imposibles
06value_counts() en cada categórica
07histplot / boxplot por variable
08corr() + heatmap — relaciones
09Anotar hallazgos y decisiones tomadas
Clave. Escribí lo que encontrás mientras lo encontrás. Un EDA sin conclusiones escritas es un notebook con gráficos lindos.
